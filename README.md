# MealMuse — Recipe Finder (Starter Project)

Responsive recipe discovery app using HTML, CSS and vanilla JavaScript. UI is ready; JavaScript behavior is intentionally left as TODOs.

## Run
1. Extract the ZIP and open the folder in VS Code.
2. Open `index.html` in your browser (Live Server recommended).
3. Keep an internet connection and complete TODOs in `script.js`.
